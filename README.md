# Week 2 – Python Practice Projects 🐍

This repository contains my Week 2 Python projects as a first-year Artificial Intelligence and Machine Learning (AIML) student. These projects helped me practise basic problem-solving, conditionals, comparisons, and string operations.

## 📂 Projects

### 1. Divisibility Checker
Checks whether a number is divisible by another number.

**Concepts practised:**
- User input
- Conditional statements
- Modulo operator (`%`)

### 2. Greatest of Three Numbers
Takes three numbers as input and determines which number is the greatest.

**Concepts practised:**
- Conditional statements (`if`, `elif`, `else`)
- Comparison operators
- Logical thinking

### 3. Character Counter
Counts how many times a specified character appears in a string.

**Concepts practised:**
- String manipulation
- Loops or string methods, depending on the implementation
- Character comparison

### 4. String Length Finder
Takes a string as input and finds its length.

**Concepts practised:**
- Strings
- User input
- The `len()` function

## 🛠️ Technologies Used

- Python 3
- Any Python-compatible code editor

## ▶️ How to Run

1. Install Python 3 if it isn't already installed.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run a project using:

   ```bash
   python filename.py
   ```

   Replace `filename.py` with the name of the Python file you want to run.
